# disco-elysium-gameboy-box-and-manual
A physical edition of the Disco Elysium Game Boy demake. This repository contains the box art, instruction manual, and cartridge sticker.I tried to recreate the design of a physical Game Boy game release for Disco Elysium.

This project is based on Colin’s Game Boy demake of Disco Elysium (@bloodystapler): 
[Disco Elysium: Game Boy Edition](https://csbrannan.itch.io/disco-elysium-game-boy-edition)
Download the .gb ROM from the official page and flash it onto a compatible Game Boy flash cartridge.

For the cartridge sticker, I used GB Label Maker 2.02, created by Hopeck.
The printable sticker is provided as both a .png and .pdf file in the sticker folder.
If you want to modify it, you can open the disco_elysium_label.gblabel project file in GB Label Maker.
You can download GB Label Maker here:
[GB Label Maker](https://sulidsanke.itch.io/gb-label-maker)

For the instruction manual, I used Soully's Game Boy Instruction Manual Figma Template, available here :
[Game Boy Instruction Manual Figma Template](https://soully.itch.io/game-boy-instruction-manual-figma-template)
The printable manual is provided as both a .png and .pdf file in the manual folder.
The Figma project file, "Game Boy Instruction Manual + Box-version-disco-elysium-gb.fig", is also included and can be opened and edited if you want to make modifications.

For the box, I used Taxicomics' Game Boy box template, available for download here: 
[DIY Retro Gamebox Template](https://taxicomics.itch.io/diy-retro-gamebox-template)
The printable box is provided as both a .png and .pdf file in the box folder.
The Figma project file, "Game Boy Instruction Manual + Box-version-disco-elysium-gb.fig", is also included and can be opened and edited if you want to make modifications.
